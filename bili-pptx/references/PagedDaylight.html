01
Design Concept

设计理念editorial × brutal × paged

技术分享的难点是“字多”。方案不靠堆装饰，而是用强烈的版式秩序承载大量信息，再用少量高饱和色块和一个与主题强相关的图形母题制造记忆点。

01 / Editorial

编辑排版

type does the heavy lifting

高反差思源宋体做标题，黑体做正文，等宽字体做路标。12 栏栅格、粗细两级线条、编号列表，让 400 字的页面依然好读。

02 / Neo-brutal

新野兽派色块

flat, loud, deliberate

直角、满版纯色、硬边位移投影，不用渐变与柔光。信号橙是唯一主角，钴蓝与青柠只做配角，制造“前沿艺术感”而不喧宾夺主。

03 / Paged

KV 块母题

memory, cut into blocks

PagedAttention 把 KV Cache 切成固定大小的块。方案把它变成内容页的小尺度视觉语言：翻页进度条、原理图物理块、章节页一小组点缀。封面与结束页则只用大字与大色块。

Mood克制 · 锋利 · 有温度

暖象牙纸底替代冷白，降低投影屏的刺眼感，也更有印刷品质感。

Audience工程师 / 技术决策者

信息密度优先；数据必须带来源，结论写进标题。

Scene投影 · 大屏 · PDF 分发

最小正文 20px（1080p），对比度全部 ≥ 4.5:1。

KeywordSwiss grid · Poster · Tech

站酷式海报张力 + 技术文档的严谨。

05
Motif & Elements

视觉母题与元件the signature

四个可复用的“签名”元素，贯穿每一页，保证整套 deck 的统一识别度。

A · KV Blocks

KV 块方格

4px 圆角小方格，五种状态：橙 / 蓝 / 青柠 / 墨 / 空，外加虚线“未分配”。只在内容页小尺寸使用，一页最多一组，不上封面与结束页。

B · Progress

翻页进度条

页眉右侧用 12 个小方格表示讲到哪：已讲为墨色，当前页为信号橙，未讲为空心。既是页码，也是母题。

硬边位移投影

10px 墨色位移投影，零模糊。每页最多一处，标记“这一页最重要的东西”。

07
Usage Rules

使用规范do & don't

让后续新增的页面依然像同一套设计。

DO · 推荐

  • 标题写结论：“推理慢又贵，问题出在显存”，而不是“性能分析”。
  • 文字页用编号列表拆分，每条 ≤ 3 行，行宽 ≤ 34 个汉字。
  • 橙色色块上一律用墨色文字；钴蓝上用纸色文字。
  • 数据标注来源与口径，推算值写明“示意”。
  • 英文术语保留原文，首次出现附中文释义。
  • 封面 / 结束页做减法：大字 + 大色块，图形总数 ≤ 3。

DON'T · 避免

  • 不使用渐变、柔和投影、紫蓝渐变、玻璃拟态。
  • 不在一页里同时铺满橙、蓝、青柠三种大色块。
  • 不使用 emoji 与装饰性图标，层级靠编号、色块和线条。
  • 正文不小于 20px（1080p 画布），不把注释灰放在下沉面上。
  • 不给卡片加单侧彩色边条；需要强调时用硬边投影。
  • 封面、结束页不堆砌小方块或多色拼贴——只用 1 块满版橙 + 1 个蓝方块 + 1 个超大字标。
